System design showcase

Fashion E-Commerce Platform

A microservices backend for an Indian streetwear brand: 10 NestJS services behind one API gateway, on PostgreSQL and Redis, in an Nx monorepo. The foundation, the authentication service and the gateway are built and tested. The remaining services are designed and in progress.

The source code is private. These pages show the architecture and design.

Engineering highlights

Authentication

  • Refresh-token rotation with reuse detection in one atomic Redis Lua script
  • Google sign-in with PKCE and a per-sign-in state cookie
  • Login throttling per number and per IP, with constant-time failures

API gateway

  • Path normalisation that refuses encoded attempts to reach internal routes
  • Per-IP and per-user rate limits in Redis that fail open
  • Request bodies streamed untouched, so webhooks arrive byte for byte

Data and delivery

  • CHECK constraints for money in paise, stock and returns, enforced in the database
  • CI with Postgres and Redis containers and a migration-drift check
  • 10 service design docs and 3 architecture decision records
